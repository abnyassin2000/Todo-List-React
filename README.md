# Todo List React

A simple and responsive Todo List application built with React.

This project was built to practice React fundamentals, state management, Context API, and localStorage.

## 🚀 Live Demo

https://todo-list-react-eight-iota.vercel.app/

## ✨ Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Visual feedback for completed tasks
- Save tasks using localStorage
- State management with React Context API
- Responsive UI

## 🛠️ Technologies

- React
- JavaScript
- CSS
- React Context API
- localStorage
- Vite
